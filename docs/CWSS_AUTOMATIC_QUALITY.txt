Internal-control test distinctions:
A mocked complete IRIS containment contract is accepted as IC:C and scores0
without changing triage or FC. This tests consumption of an existing accepted
proof, not the ability of IRIS to prove every guard. A separate actual Java
normalization/containment example currently yields IRIS UNKNOWN; automatic
IC stays UK and score remains3.6. No AST/IRIS code is changed to force a result.

Reproducibility and validation:
Fixed inference version, deterministic traversal, canonical hashes, same Decimal
engine. Identical snapshots produce identical vector/hash/score; SQLite publication
is an idempotent atomic mode pair. Replays use snapshots, including original
version and engine hashes. Changed context creates new revisions, not archive
rewrites. Tests cover competing writes, no-auth writes, source mismatch,
unsupported owner/overload, slot gaps, stale source, ambiguous security, modified
snapshots, path traversal/symlinks, inventory bounds and config-secret exclusion.

Limits:
Local static capability is not deployed reachability or complete impact. Only a
small synchronous Spring syntax and an entire simple security grammar are
supported. Unsupported/inherited/dynamic methods and external libraries stay
Unknown. Deployment configuration is scenario evidence, never runtime truth.
Kubernetes service ownership and firewall/topology are not resolved. Docker
EXPOSE is observed only, not evidence of Internet exposure. BI/EC/privileges and
FC remain Unknown automatically. High-risk deployments can still have low,
incomplete numeric CWSS until their missing facts are independently established.
Full verified prioritization still uses V2 context/attestation; automatic mode
never imports a machine suggestion into attestation. Source snapshots use V2's
private localhost trust boundary; no multi-tenant authorization was added.
